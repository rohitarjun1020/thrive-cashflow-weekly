Scope: index.html, the Thrive Living weekly cash-flow dashboard (v2, "Front Desk"). Mode: Operate.
Audience: Thrive's owners and the Strategy Studio CFO team, in a weekly review on a laptop, a projector or a phone; sometimes printed.
Task: read the verdict and the cash position, see what needs attention and what is due, drill from a week, month or head to the lines behind it, test a what-if, ask a question, export.
Constraints: every figure from the weekly Cash Flow workbook; actual vs planned decided by the file's save date; zero cost (Google Fonts, no paid assets, no API keys); English only; no emoji; modest type sizes; theme never sits behind numbers. The old v1 page is kept as dashboard-classic.html.
Decision: the user chose the pick "Front Desk" from three directions (assigned "The Thrive Line", pick "Front Desk", challenger "Overhead Signs") on 2026-11-12.

## Direction contract
THESIS: A co-living front desk. Headline figures hang as enamel key tags with rubber status stamps; the latest weeks hang on a key rack; the rest of the page is the register on a calm ground. Refuses the generic bento SaaS board of v1 and the Poppins-plus-serif-capitals look the user rejected.
OWN-WORLD: Charcoal desk header (#22262A) with the THRIVE wordmark; warm ground #F2F1EE under white cards with hairline borders; one oak desk band (#E7D9C6 family) holding the verdict and the key tags; brass (#8C5A26 light / #D9A367 dark) owns every live state (selection, focus, current week, links). Gain #0E9F6E / loss #E5484D (dark #2AAE7B / #DC3F46) only for money direction and overdrawn state, always with a sign, a stamp or position. Archivo variable (wdth 62-125, wght 400-800) as the single family with tabular figures; stamps use the condensed width; the wordmark uses the expanded width. Charminar line art appears only on the passcode gate and in the footer.
STORY: The viewer reads the verdict sentence and the five key tags (Opening, Money in, Money out, Net, Closing with stamps), checks the key rack and the latest/next week cards, reads Needs attention, then the cash-flow chart and Upcoming payments, the closing-balance chart with overdrawn shading, spend by category, landlords as a building drawn to scale, and the register (statement and transactions) with CSV and copy-for-Excel. What if and Ask AI are tabs in the header.
FIRST VIEWPORT: Charcoal header with view tabs (Front desk, What if, Ask AI), print, theme and lock icons; one sticky filter row (presets, from/to, category, alert level, planned weeks); the oak desk band with greeting, file date, verdict, five key tags and the bank/Razorpay balance line.
FORM: user-chosen direction "Front Desk" (impeccable's pick), seed:7db941b275fc28bb. Signature move: stamped key tags and the key rack of weeks; landlords drawn as building floors whose widths are each landlord's monthly rent.
