# Thrive Living – cash-flow dashboard

Static dashboard built from `Thrive_Weekly Cashflow 11112026.xlsx` (Cash Flow, Bank Statements FY 24-26 and Razorpay statements sheets) for Thrivescape Ventures Pvt Ltd.

- `index.html`, `styles.css`, `app.js`: the page
- `data.js`: figures extracted from the workbook (no estimates)
- `vendor/`: Apache ECharts 5.5.1 (Apache-2.0, see `vendor/ECHARTS-LICENSE.txt`)
- `fonts/`: Public Sans (SIL OFL, see `fonts/OFL.txt`)

To refresh, re-run the extractor against the new workbook and replace `data.js`.
